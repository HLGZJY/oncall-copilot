# M0–M9 路线图

## 模块与优先级

| 模块 | 内容 | 优先级 |
|---|---|---|
| M0 | demo 系统 + 遥测 + 故障注入脚本库 + 告警规则 | P0 |
| M1 | 告警接入：Webhook、指纹去重、上下文拉取 | P0 |
| M2 | 降噪分类：规则预筛 + LLM 双通道 | P0 |
| M3 | **自主根因调查循环**（自研 ReAct） | P0 核心 |

| M9 | 过程可观测（token/成本埋点） | P2 可并入 M7 |

## 裁剪顺序（时间不够时按序砍）

**M3 / M4 / M7 不可砍。**

## 验收硬口径（实测回填，不得虚构）

降噪 ≥80% 且 0 漏报；Top-1 ≥70% / Top-3 ≥85%；≤15 步 / ≤5 分钟 / ≤¥0.5；写操作 100% 过确认门；证据链 100% 落库；≥2 模型 × ≥8 剧本矩阵。
