# _sources/ — 原始母本区

**这里的每份文件都标了 `status: archived`：不更新、不作为开发权威、日常开发不要直接引用。**

存放的是外部调研笔记与早期素材。它们的结论已经被拆解、提炼、重写进 `docs/` 下对应的主题文件——那里才是权威。

## 为什么还要留着

提炼是一次有损压缩。当 `docs/` 里的某条结论语焉不详、或你想知道"这个数字/这个判断最初从哪来"时，回到这里翻母本，比重新调研便宜。

## 纪律

1. **只读**：发现母本与 `docs/` 不一致时，改 `docs/`，不改母本。
2. **不新增**：新的调研成果直接写进 `docs/` 对应主题文件，不要往这里堆。
3. **不引用**：任何 `docs/` 文件的正文中如需指向母本，必须显式写成"原始母本"并给出完整路径，让读者知道这是回溯而非权威。
