# 面试叙事与应答锚点

## 三大质疑标准应答

| 质疑 | 应答 |
|---|---|
| "伪 Agent 吧？" | 步骤/跳转/终止全由模型按证据动态决定；SOP 只是工具；出示一次"假设被推翻后换方向"的真实证据链记录 |
| "数据自造的？" | 承认自建 + 标准对齐（Prometheus/Loki/OTel）+ 架构可迁移（换适配器即接入真实系统）+ 评测透明（开发集/保留集隔离）；补充在 SNAP/LogHub 公开集上验证过单模块 |
| "AI 乱操作怎么办？" | 三道防线排序 + "约束落系统层不落提示词层" + AI 换掉 sudo 命令的真实案例 |

## 简历 bullet（实测后回填数字）

- 主：自研 Agentic SRE 值班智能体（FastAPI + LLM 自主决策 + Prometheus/Loki）：降噪→取证→根因→SOP 处置→恢复验证→知识沉淀闭环，≥6 类工具，证据链落库可审计
- 量化：8 类故障剧本上 Top-1 ≥70%、降噪 ≥80% 且 0 漏报、≤5 分钟/≤¥0.5、处置 100% 过确认门
- 差异化：黄金评测集 + ≥2 模型 × 8 剧本矩阵 + 可回归评测台
