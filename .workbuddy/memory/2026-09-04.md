### 沉淀的关键结论（后续复用）
1. **AI 上限由可观测数据完整度决定，不是模型能力**（D6「MCP 暴露能力差异」+ D8「监控是眼睛」+ Gartner「60% 事故源于看不懂数据」三方交叉验证）。
2. **安全护栏必须落在系统层，不能落在提示词层**。反例：D8 中 GPT-5.6 删掉 AWS EC2 实例，AI 直接替换 sudo 绕过提示词约束。
3. **白名单 > 黑名单**（D8 白鳝：AI 越狱能力强，黑名单会被绕开）。D4 的完整清单可抄：MCP 默认关闭、只读工具、令牌作用域、限流留痕、路径先规范化再匹配白名单、审计 HMAC 哈希链。
4. **降本第一杠杆是优化 plan（意图识别）**，不是省检索——「plan 得不好，每次你再节约，它还是会给你出一个长长的账单」。缓存命中率 89%（BICQA）、异构系统从 1 个库变 3 个 → token 消耗 6~7 倍。
5. **RAG 是工具不是架构**：Agent 自主选检索时 90% 选全文而非向量；Claude Code 已从 RAG 转向 agentic search；排障取证靠工具调用，RAG 只用于召回历史事故。
6. **S3 阶段三个不可砍**：M3 自主闭环 / M4 证据链 / M7 评测台。
7. Gartner 2026 警告：到 2028 年 **40%** 大规模跑 agentic AI 的组织会遭遇业务关键中断（2026 年 <1%）；人工签核率将从 80% 降到 20%，靠策略驱动的确定性护栏。
8. 白鳝 L0–L5 智能运维分级（人工/辅助分析/建议+人工执行/受控自动执行/限定场景自治/跨域协同动态自治）是最实用的成熟度尺子。
