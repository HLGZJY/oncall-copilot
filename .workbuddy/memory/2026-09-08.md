### 本票新增的踩坑与约定（后续 M3+ 直接复用）

1. **oncall.db 缺列会静默致命**：M1 遗留库无 `classification_json`（`create_all` 不 ALTER）。切 M2 前必须备份（`oncall.db.bak-<日期>`，已入 .gitignore）后删库重建，否则分类写库即炸。
2. **分类时机决定通道归属**：规则③ `stale_replay` 是「resolved_at < now」→ **先等 firing 就分类，再 cleanup**；恢复后再分类会全被规则直判 false_positive（真告警会被误归档）。3 剧本验收必须「inject → 等 firing → ingest 落库 → POST /classify → cleanup」。
3. **守卫测试 `test_unit_tests_do_not_import_real_sdks` 会拦 openai import**：为钉死「SDK 异常 → 契约异常」映射，在 `tests/test_architecture_guards.py` 新增显式豁免常量 `SDK_EXCEPTION_MAPPING_TESTS`（只 import 异常类型、不构造 client）；实质防线仍是 conftest 的 autouse 断网 fixture。
4. **真实 usage 的留存通道**：`classification_json.tokens/cost` 是 G8 估算口径且 D-19 契约冻结，不为实测改字段 → 真实 usage 走 **structlog `llm_call` 日志**，用 `docker logs oncall-demo-oncall-1 | grep llm_call` 取；同卡复现（in-container 调 `client.classify`）可补齐日志启用前的计量。
5. **few-shot 在容器内要指对目录**：compose 挂 `/app/repo`，容器内 `datasets/golden/dev` 需 `ONCALL_GOLDEN_DEV_DIR=/app/repo/datasets/golden/dev`，否则静默空样本池（prompt 变弱且无报错）。
6. **qwen3 兼容模式**：JSON Mode 用 `response_format={"type":"json_object"}`；关思考用 `extra_body={"enable_thinking": false}`（不关则思考 tokens 计入输出计费且拖长延迟）。
7. **降噪率统计切片**：`snapshot_alert_rows` 按 id 序返回但无 id 字段，多剧本分段统计要按「跳过行数 + 取 N 行」切片，别把别的剧本的行算进来。
8. **Git Bash 单条命令 120s 超时**：剧本等待用 `sleep 100~115` + 显式 `timeout` 参数，别一次 sleep 150+（会被 SIGTERM）。
